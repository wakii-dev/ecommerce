## ACCEPTANCE (user-visible)

1. Từ storefront bấm giỏ → header shell hiện đúng logo + search + cart + account (không còn "rớt cấp"); click badge giỏ → drawer trượt ra hiện đúng line items + tổng; guest lẫn logged-in đều thấy; ESC/click-outside đóng.
2. Giỏ hàng: đổi số lượng bằng stepper (bàn phím được), xóa line có confirm; áp mã giảm giá ngay ở cart → sang checkout mã vẫn áp dụng.
3. Checkout 3 bước: stepper hiển thị + nhảy bước bằng keyboard; gõ SĐT sai → báo lỗi ngay khi blur (không chờ submit); mobile bàn phím số đúng kiểu; summary hiện ảnh sản phẩm.
4. Bật dark mode toàn flow cart→checkout→confirmation: không còn ô màu lệch (pay-warning/stepper), mọi icon là SVG không emoji.
5. Confirmation CTA đưa về trang chủ; polling trạng thái đơn vẫn hoạt động đúng (không đụng logic).
6. e2e subset (golden-path checkout, cod-checkout, saga-fail) XANH + unit mfe-checkout xanh.
