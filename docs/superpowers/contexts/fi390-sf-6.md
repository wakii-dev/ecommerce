## Spec slice (chỉ phần SF-6 chịu trách nhiệm)

1. **Cross-surface consistency sweep**: đi 5 surfaces (storefront home/PLP/PDP, shell header, cart/checkout, account, admin) — spacing/typography/motion đúng 1 nguồn tokens (không app tự chế), icon SVG đồng bộ, pill/badge tints nhất quán; phát hiện lệch → ghi + fix task về SF sở hữu. **Tiêu chí cơ học (epic §7):** keyframes chỉ ở đúng 4 file (`app.css`, `page.css` ×3) + ui-kit.css — grep `@keyframes` toàn apps/ phải ra đúng các file đó; `grep '<a href="/' apps/storefront-web` = 0 hit (next/link generated không ra pattern này); emoji-icon check vào JSX text node (ThemeToggle.tsx:21 có "✓" trong COMMENT — naive grep false-positive, scope grep vào string literal JSX hoặc run-time render).
2. **Dark-mode 4-trạng-thái sweep (scripted)**: matrix storefront-admin × light/dark trên các page định danh (home, PLP, PDP, cart, checkout step 1-3, confirmation, account, orders, order detail, admin dashboard + products + orders); contrast AA theo method §4.7 spec — script tính contrast từ computed styles (không thuần mắt); hex lệch/tint sai → fix task.
3. **prefers-reduced-motion sweep**: bật reduced-motion (OS/emulation) → mọi animation tắt (ken-burns, reveal, drawer slide, toast, shimmer), nội dung vẫn hiện đủ; verify cả Next (storefront) lẫn Vite apps.
4. **Responsive 375/768 sweep**: mobile 375px + tablet 768px toàn surfaces — storefront (mobile nav, sticky ATC, grid 2-col), shell header wrap, checkout forms 1-col, account side-nav collapse, admin layout; không vỡ layout/ngang cuộn.
5. **A11y keyboard-only flow**: rút chuột — login → duyệt home → thêm giỏ → drawer → checkout 3 bước → confirmation; focus order hợp lý, focus-visible hiện, ESC đóng overlay, không focus trap chết; Tab/arrow hoạt động (stepper, tabs, user menu).
6. **i18n parity sweep**: vi/en toàn hệ — grep hardcode tiếng Việt còn sót trong JSX (P1 = 0), key vi↔en thiếu (2 hệ: storefront COPY module + @ecommerce/i18n), aria-label keys.
7. **e2e FULL suite**: cả 14 specs (`frontend/e2e/tests/*.spec.ts`) trên stack nhánh đích — fix selector vỡ bằng data-testid fallback (theo ADR SF-1) TRONG specs hoặc trả fix-task về SF nếu classname surface đổi; full-stack cần gateway+seed — alt-ports per worktree (pattern fe-e2e-isolated; docker half-death recovery nếu cần).
8. **Unit tests toàn monorepo**: 27 file FE (vitest ×5 apps + ui-kit + i18n) + token-regression — XANH trên nhánh đích.
9. **Perf/CLS đo**: Lighthouse/web-vitals CLS + LCP trên home + PDP (sau font + skeleton) — target CLS < 0.1, ghi nhận số liệu trước/sau (baseline từ main nếu lấy được; nếu không, ghi nhận-only + note); font load đúng (computed font-family).
10. **Visual walkthrough record + sign-off**: record walkthrough video/screenshots 5 surfaces (Serve nhánh đích + Orca browser tab cho user xem) → epic comment; chuẩn bị final verify cho STORY-COMPLETE (smoke + tests + visual trên nhánh đích).
