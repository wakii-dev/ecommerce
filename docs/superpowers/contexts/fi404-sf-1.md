## Spec slice (chỉ phần SF-1 chịu trách nhiệm)

1. **config-audit trục (a) env vars**: extract mọi `${VAR:default}` từ `backend/**/application*.yml` + `@Value("${...}")` annotations + `backend/gateway/src/main/resources/gateway-routes.yml` (URI defaults) → so với `environment:` blocks trong `docker-compose.yml`. Classify machine-checkable: **DANGEROUS** = default match `localhost|127.0.0.1` + consumer service có compose entry + compose không set VAR đó (pattern LOG_URI); WARN = compose set nhưng default khác value; OK = set khớp. Whitelist FE-host: storefront/shell/FE dev chạy host là chủ đích (default localhost:3000/5173 trong FE code không flag).
2. **Trục (b) volume mounts drift**: với mỗi service container, collect file/path code đọc lúc boot (grep `JwtDecoderConfig`, PEM/keystore paths, `@Value` path vars) ↔ compose `volumes:` mount — thiếu mount/path lệch = DANGEROUS (pattern JWT keys: `JWT_PUBLIC_KEY_PATH=/keys/jwt-public.pem` cần `./infra/keys:/keys:ro`).
3. **Trục (c) compose value drift**: settings quan trọng trong compose so giá trị hợp lý — `command:` flags (max_connections!), healthcheck timeouts, resource limits; flag khi default thấp hơn nhu cầu đã biết (11 JVM pools).
4. **s2s-auth-matrix STATIC** (KHÔNG HTTP call): enumerate MỌI HTTP client service→service (grep RestClient/WebClient/RestTemplate/`http://` service-name refs): ordering 6, cart 2, catalog 1, notification 3, partner 3... Với từng pair: URL path gọi (resolving env/path property) → endpoint cần auth gì (đọc SecurityConfig service đích: permitAll/admin/authenticated) → client có gắn token không → verdict EXPECTED OK/DANGEROUS/GAP. Bảng markdown.
5. **RBAC expected matrix**: guest/user/admin × MỌI admin endpoints (đóng list: catalog admin products/categories, ordering admin coupons, inventory admin stocks+low-stock, log admin events, partner admin, RMA admin, newsletter, audit) + public paths điểm danh. Verdict EXPECTED per cell.
6. **Report**: `docs/superpowers/qa/report-sf1.md` — classify + matrix + findings list; **exit-code semantics**: 0 = 0 finding CHƯA fix; 1 = có finding chưa fix; 2 = script error. Finding FIXED ghi status FIXED (không ảnh hưởng exit).
7. **makefile target `qa-audit`**: chạy 2 script + exit code propagate.
8. **Makefile + docs**: target comments + README QA section ngắn.
9. **unit smoke + self-test fixture negative**: script có `--self-test` chạy trên FIXTURE compose thiếu env (file fixture, KHÔNG tạm revert compose thật — read-only) → DANGEROUS bắt được.
10. **probe contracts freshness**: diff `contracts/` generated client ops vs controllers thực tế — stale → finding riêng (không tự sửa).
11. **epic comment findings P0**: gộp vào task report — đăng report tóm tắt lên FI-404 (`orca linear comment add --id FI-404 --body-file -`).
