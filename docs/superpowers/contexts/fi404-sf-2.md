## Spec slice (chỉ phần SF-2 chịu trách nhiệm)

1. **Harness skeleton**: `scripts/qa/fresh-boot-harness.sh` — stages có timestamp log (`/tmp/qa-fresh-boot-<ts>.log`): GATE → BACKUP → DOWN → BUILD → UP → SEED → PROBES; mỗi stage in `[stage] HH:MM:SS (elapsed)`.
2. **Gate kép (P0)**: (a) env `QA_FRESH_BOOT_CONFIRM=1` bắt buộc (coordinator set sau consent user 1 lần ở story level — bracket là record); thiếu → refuse exit 3; (b) demo-idle check: port-owner + app containers > 0 → REFUSE (KHÔNG có --force — consent story-level không thay thế idle-check từng lần; coordinator ping user per-run rồi mới set confirm flag); (c) `docker system df` + disk free ≥ 20GB + RAM VM check.
3. **BACKUP + RESTORE-TEST**: `pg_dump` TỪNG DB (9 DB trong 1 container postgres — `docker compose exec -T postgres pg_dump -U postgres -d <db>`) → `backups/qa-<ts>/<db>.sql.gz`; **restore-test**: `createdb qa_restore_test` → `pg_restore`/`psql` restore → sanity query (select 1 bảng) → drop. Backup fail = refuse wipe.
4. **DOWN -v**: `docker compose --profile full --profile stripe down -v --remove-orphans` (wipe volumes — đã backup).
5. **BUILD serialized** (stack ĐÃ tắt — daemon wedge ×3): `docker compose --profile full --profile stripe build` — log thời gian; nếu daemon 500 giữa build → detect + hướng dẫn restart daemon (`pkill -f com.docker.backend; open -a Docker`) + resume từ stage build (idempotent).
6. **UP + health gates theo tầng**: infra (postgres/redis/rabbitmq/mongo/es/minio healthy) → JVMs (actuator UP từng service, timeout 4 phút) → FE (frontend-web/storefront-web Up) → gateway :8080/actuator/health.
7. **SEED**: `make seed` — assert output "XONG"; fail → log + exit 4.
8. **PROBES stage**: (a) 1 ảnh MinIO load được HTTP 200 (pattern URL /media/** — nếu fail = finding MinIO-reseed, KHÔNG giấu); (b) login admin@demo.vn/admin123 200; (c) 1 add-to-cart guest 200; (d) events API admin 200; (e) **live RBAC spot-check HARDCODED** (độc lập SF-1 — 3-5 cell: guest→admin-write→401/403; admin→product-PUT→2xx); (f) **port-owner check** (detector lớp 5): :3000/:5173/:5175-78/:9099 không có process lạ (`lsof`).
9. **Makefile target `qa-fresh-boot` đặt CẠNH block `seed` (~dòng 105 — khác vùng với qa-audit cuối file của SF-1); conflict expected khi rebase → keep-both-blocks.** + `.gitignore backups/` ngay trong task skeleton + docs README ngắn (runbook restore-từ-backup: createdb + psql restore từng DB + seed lại).
10. **Dry-run 1 lần TOÀN BỘ** (trên chính máy này, sau gate) — đo thời gian từng stage + tổng; log vào report-sf2.md. Build dài 10-15' → `run_in_background` + poll log `/tmp/qa-fresh-boot-*.log`.
