6. **Fix batch 2** (nếu có) + re-run cap cuối.
7. **Journeys green cuối + legacy regression**: cả admin-journey + data-lifecycle trên env fresh sau fix; `legacy-e2e-regression-run` — full `pnpm e2e` 15 specs cũ + 2 mới, serial, env fresh sau batch cuối (owner success §5.6; nếu fix làm đỏ expectation spec cũ → cập nhật spec cũ trong CÙNG fix commit + ghi bug-register).

9. **Epic comment tổng**: bug-register tóm tắt + merge map + thời gian harness + escalate list.
10. **Demo restore + sign-off**: đảm bảo stack :8080 seeded-green sau sweep (harness đã seed; nếu harness chạy cuối = đã fresh-green) → smoke login + cart + admin → sign-off epic.
