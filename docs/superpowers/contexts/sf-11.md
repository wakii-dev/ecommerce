## Spec slice (chỉ phần SF-11 chịu trách nhiệm)

1. **`backend/services/partner-api`** (port 8091, db_partner) từ template — **Open API module cho đối tác** (D19): namespace riêng `/open-api/v1/**`, KHÔNG dùng JWT customer — auth riêng.
2. Flyway: `partners` (id, name, status ACTIVE/SUSPENDED, webhook_url nullable, webhook_secret, rate_limit_per_min, created_at), `api_keys` (id, partner_id, key_hash sha256, prefix (8 ký tự đầu để nhận diện), scopes varchar[], expires_at nullable, revoked_at).
3. **Auth + rate-limit**: filter đọc `X-API-Key` → hash lookup (constant-time compare) → check ACTIVE + scopes + rate-limit per key (Bucket4j in-memory — đủ MVP; note ADR Redis-backed khi scale). Key sai/hết hạn/revoke → 401 problem+json; vượt limit → 429 với `Retry-After`.
4. **Endpoints theo `partner-api.yaml`**:
   - `GET /open-api/v1/products` + `/products/{slug}` + `/categories` + `/search?q=` — gọi catalog REST (service-token), trả shape partner (không lộ nội bộ).
   - `POST /open-api/v1/orders` — tạo đơn cho partner: payload `{partner_order_ref, customer{email,name,phone,address}, items[{product_id, variant_id, qty}], coupon_code?}` → gọi ordering (re-price/reserve flow nội bộ) → `{order_id, status, client_secret?}`; idempotency qua `partner_order_ref` unique.
   - `GET /open-api/v1/orders/{id}` — trạng thái đơn (chỉ đơn của partner này).
   - **Webhook**: partner đăng ký `webhook_url` + secret (CRUD qua endpoint admin trong partner-api hoặc seed); consume `order.*` events (RabbitMQ) → lọc đơn thuộc partner → POST JSON `{event, order_id, status, occurred_at}` + header `X-Signature: HMAC-SHA256(secret, body)`; **retry exponential 3 lần** → DLQ; verify bằng secret ở phía partner (docs hướng dẫn).
5. **Docs portal**: springdoc aggregated tại `/open-api/v1/docs` (Swagger UI) — mô tả auth, rate-limit, webhook signature verification, example curl cho từng endpoint.
6. **Seed** (profile seed): 1 partner demo (`DEMO-PARTNER`, key in ra log 1 lần khi seed, webhook_url trỏ http://localhost:9999/webhook-test).
7. **Infra**: gateway append route block `/open-api/**` → partner-api (public, KHÔNG yêu cầu JWT — auth là API key); compose append block + Makefile target; **`infra/db/init/01-create-dbs.sh` append `db_partner`** (append-only — file thuộc SF-1, edit tối thiểu 1 dòng); events consume qua common-lib (idempotent).
8. **IT**: auth (sai key 401, đúng key 200, revoke → 401), rate-limit (vượt → 429), catalog proxy, order create idempotency (cùng partner_order_ref → 1 đơn), webhook HMAC signature verify (test receiver), scope enforcement.

## ACCEPTANCE (user-visible)

- `curl -H "X-API-Key: <demo-key>" :8091/open-api/v1/products` → JSON catalog; key sai → 401; key revoke → 401.
- Vượt rate-limit → 429 + Retry-After.
- `POST /open-api/v1/orders` → đơn tạo thật trong hệ thống (thấy trong admin); gửi lại cùng `partner_order_ref` → không double đơn.
- Đơn đổi trạng thái → test receiver (localhost:9999) nhận POST với `X-Signature` HMAC đúng secret; signature sai ở phía partner → reject được (docs có code mẫu verify).
- `/open-api/v1/docs` mở Swagger UI với đầy đủ endpoints + hướng dẫn auth/webhook.
- **§5.13** assert đạt.
