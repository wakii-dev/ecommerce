## Spec slice (chỉ phần SF-12 chịu trách nhiệm)

1. **`backend/services/affiliate-service`** (port 8092, db_affiliate) từ template — **Affiliate module** (D20): Flyway — `affiliates` (id, user_id unique, code unique 8 ký tự, status PENDING/APPROVED/SUSPENDED, commission_rate numeric(4,2) nullable → fallback env `AFFILIATE_DEFAULT_RATE=5`, payout_note, created_at), `clicks` (id, code, occurred_at, ip_hash, user_agent_hash), `ledger` (id, affiliate_id, order_id unique, order_total, commission, status EARNED/PAID, created_at), `processed_messages`.
2. **APIs theo `affiliate.yaml`**:
   - `POST /api/affiliate/register` (JWT) → PENDING; `GET /api/affiliate/me` (code, rate, stats); `GET /api/affiliate/me/stats?days=30` (clicks, conversions, earnings tổng/chờ thanh toán).
   - `GET /api/affiliate/track?code=<code>` — **public, KHÔNG auth**: validate code ACTIVE → set cookie `aff_ref` (30 ngày, httpOnly, path `/`) + record click (idempotent nhẹ: 1 click/IP/10'); code sai → vẫn set-nothing, trả 204 KHÔNG lỗi.
   - `GET /api/affiliate/resolve?code=` (internal cho ordering validate lúc POST /orders) → `{affiliate_id, code, rate}` hoặc 404.
   - Admin: `GET /api/affiliate/admin/affiliates?status=`, `POST /{id}/approve|suspend`, `PUT /{id}/rate`.
3. **Ledger consumer**: consume `order.confirmed` (fat payload có `affiliate_code` nullable) → code có affiliate APPROVED → tạo ledger entry `commission = order_total × rate/100` (round 2 chữ số; VND làm tròn xuống). Idempotent (order_id unique). Order FAILED/CANCELLED → KHÔNG tạo (nếu đã tạo do race → đánh dấu đảo bằng consumer order.cancelled/failed: xóa entry EARNED chưa PAID).
4. **Wiring edits (nhỏ, file của SF đã merge — additive)**:
   - `storefront-web` (SF-4): middleware/layout capture `?ref=` → gọi `GET /api/affiliate/track` (client-side 1 lần/session) + cookie giữ nguyên — 1 file middleware.ts + rewrite URL bỏ `?ref` (sạch URL SEO).
   - `mfe-checkout` (SF-6): đọc cookie `aff_ref` → thêm `affiliate_code` vào POST /orders payload (theo ordering.yaml — field nullable frozen).
5. **Account dashboard** (mfe-account, file-slice CHỈ `pages/affiliate/*`): đăng ký affiliate (nếu chưa có — trạng thái PENDING chờ duyệt), code + **link generator** (copy link sản phẩm với ?ref=), stats cards (clicks, conversions, earnings), bảng ledger. Shell manifest append `/account/affiliate`.
6. **Admin** (mfe-admin — SF-7 đã merge, SF-12 thêm trang LIVE): `pages/affiliates` (append route + nav entry — additive edit vào mfe-admin của SF-7): table affiliates (filter status), approve/suspend, sửa rate, stats mini. KHÔNG đụng file khác của SF-7.
7. **Infra**: gateway append route block affiliate; compose append + Makefile target; `infra/db/init/01-create-dbs.sh` append `db_affiliate` (append-only).
8. **IT**: track cookie + click record; register → PENDING → approve → code ACTIVE; consumer tạo ledger đúng rate từ order.confirmed synthetic; idempotent (re-delivery không double); cancel order → entry EARNED bị gỡ; admin đổi rate → đơn sau dùng rate mới; dashboard stats đúng.

## ACCEPTANCE (user-visible)

- User đăng ký affiliate → PENDING; admin duyệt → ACTIVE với code + rate mặc định 5%.
- Khách click link `?ref=CODE` → URL sạch (không còn ?ref), cookie 30 ngày; click được track.
- Mua hàng qua cookie đó → đơn CONFIRMED → dashboard affiliate: conversion +1, earnings = total × 5% (hoặc rate riêng).
- Admin suspend affiliate → link không track nữa (không lỗi cho khách); admin đổi rate → đơn sau áp rate mới.
- Order bị hủy/fail sau khi có ledger EARNED → entry bị gỡ.
