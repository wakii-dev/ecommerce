## Spec slice (chỉ phần SF-13 chịu trách nhiệm)

1. **Password reset (A1)**: identity-service — `POST /api/identity/password/forgot` (email → reset token 30' lưu db_identity, luôn trả 200 không lộ email tồn tại) + `POST /api/identity/password/reset` (token + password mới, revoke mọi refresh token cũ). Email gửi qua notification-service (REST nội bộ hoặc event `user.password_reset_requested` — agent chọn theo convention, ghi ADR ngắn). Trang `/forgot-password` + `/reset-password?token=` trong mfe-account.
2. **COD (A2)**: payment-service — `CodPaymentAdapter` (SPI impl: createIntent → không-op trả `cod:true`, capture lúc giao hàng thành công qua admin action). ordering saga: `payment_method=cod` → bỏ bước Stripe intent + không chờ webhook → sau reserve → **CONFIRMED** luôn (state machine thêm path PENDING→CONFIRMED cho COD). Checkout UI thêm chọn phương thức (Stripe / COD) ở bước payment.
3. **Upload ảnh MinIO (A3)**: compose thêm `minio` (:9000 API, :9001 console) + bucket `products` (public-read dev); catalog-service `POST /api/catalog/admin/uploads` (multipart, 5MB, jpg/png/webp, tên file uuid) → MinIO → trả URL `/media/products/<uuid>` (gateway route `/media/**` → MinIO). Admin product form: nút upload thay/chắp thêm URL list.
4. **Abandoned cart email (A4)**: cart-service scheduler — cart user (đã login, có email) có items ≥ 2h không cập nhật → publish event internal → notification gửi email nhắc (1 lần/cart/24h — flag Redis).
5. **Audit log viewer (A5)**: log-service thêm `GET /api/log/admin/events` (ADMIN — gateway route guard + param filter eventType/from/to, paginate 50) đọc Mongo `event_log`; mfe-admin trang `pages/audit` (append — file-slice SF-13): table + filter + pagination. Exception đã ghi ADR: endpoint nội bộ admin, không có OpenAPI freeze riêng.
6. **Recently viewed (A6a)**: storefront-web — localStorage `recently_viewed` (max 12, PDP ghi) + section "Đã xem gần đây" ở home (client component).
7. **Related products (A6b)**: PDP — "Sản phẩm tương tự" qua ES `more_like_this` (name/description/category) — endpoint `GET /api/catalog/products/{slug}/related` (catalog, ES engine) — **thêm vào catalog.yaml? KHÔNG — contracts đã freeze**: dùng endpoint search hiện có với `similar_to=slug` param? → đây là gap: xử lý qua coordinator amendment TRƯỚC khi code (flag REQUIREMENT-GAP lên epic ngay khi start nếu chưa thấy amendment).
8. **GA4/GTM (A7a)**: storefront-web + shell — script GA4 theo env `NEXT_PUBLIC_GA_ID`/`VITE_GA_ID` (không có ID → không load); pageview + purchase event trên confirmation.
9. **Export CSV (A7b)**: ordering + catalog admin endpoints `GET .../export.csv` (stream, ADMIN) + nút export trong mfe-admin orders/products tables.
10. **Newsletter (A8)**: footer storefront-web form subscribe → `POST /api/identity/newsletter` (email unique, bảng newsletter_subscriptions db_identity) → welcome email qua notification; admin xem danh sách (trang đơn giản).
11. **E2E regression essentials**: Playwright specs cho reset password, COD checkout, upload ảnh, related products; chạy lại golden-path cũ (không được vỡ).

- Quên mật khẩu → email Mailpit có link → đặt mật khẩu mới → login được bằng mật khẩu mới; email không tồn tại không lộ.
