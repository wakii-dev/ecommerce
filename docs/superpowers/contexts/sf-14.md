## Spec slice (chỉ phần SF-14 chịu trách nhiệm)

1. **RMA đổi trả (B1)** — trong ordering-service: Flyway `rma_requests` (id, order_id, user_id, status REQUESTED→APPROVED→RECEIVED→REFUNDED / REJECTED, reason, items jsonb, created_at). APIs: `POST /api/ordering/me/rma` (đơn DELIVERED, trong 7 ngày — env `RMA_WINDOW_DAYS=7`, chọn items + lý do) → REQUESTED; `GET /api/ordering/me/rma` (list của tôi); admin: `GET /api/ordering/admin/rma?status=`, `POST /{id}/approve|reject|mark-received|refund`. `refund` → gọi payment-service `POST /api/payment/refunds` (Stripe adapter refund có sẵn) → REFUNDED + email mỗi bước (notification — template RMA). RMA emails consumer/notification templates thuộc SF-14 (file-slice trong notification-service: templates + rma listener).
2. **GHN shipping (B2)**: ordering-service `GhnClient` (env `GHN_API_URL`, `GHN_TOKEN`, `GHN_SHOP_ID` — không có token → fallback flat-fee cũ, degraded). `GET /api/ordering/shipping/methods?province=&district=` → methods từ GHN (services + fee theo weight/address) hoặc flat-fee fallback; POST /orders nhận `shipping_method` → fee thật thay flat-fee; sau khi đơn SHIPPED → tạo vận đơn GHN (`tracking_code`) + `GET /api/ordering/me/orders/{id}/tracking` (trạng thái vận đơn từ GHN). Checkout UI: chọn method + hiển thị phí thật; my-orders detail: tracking block.
3. **Loyalty điểm (B5)** — trong affiliate-service (cùng nhà ledger, file-slice riêng `loyalty/`): Flyway `loyalty_accounts` (user_id unique, balance, total_earned), `loyalty_ledger` (id, user_id, order_id nullable, type EARN/REDEEM/ADJUST, points, created_at). EARN: consume `order.confirmed` → `points = total / 10000` (1% — env `LOYALTY_EARN_RATE`), idempotent. REDEEM: ordering POST /orders nhận `use_points: int` → validate REST affiliate-service (`/internal/loyalty/redeem` — trừ điểm nguyên tử, reserve kiểu coupon) → `points_discount` trừ vào total; order FAILED/CANCELLED → hoàn điểm (consumer). UI: account dashboard block điểm (mfe-account `pages/affiliate/*` chắp section — file-slice SF-12 đã merge) + checkout UI dùng điểm (mfe-checkout edit nhỏ). Admin: chỉnh điểm thủ công (mfe-admin pages append).
4. **Admin pages (file-slice mfe-admin của SF-7 — append)**: `pages/rma` (queue duyệt + actions) + `pages/loyalty` (tra cứu + adjust) — nav entries additive.
5. **Emails**: notification-service — file-slice SF-14: RMA templates (approved/received/refunded/rejected) + consumers/listeners tương ứng; sử dụng pattern notification có sẵn.
6. **IT**: RMA lifecycle state guards (sai trạng thái → 409; ngoài 7 ngày → 400); refund gọi Stripe thật (test key) hoặc mock fallback; GHN mock (WireMock) fee methods; loyalty earn idempotent + redeem concurrent + hoàn điểm khi cancel; emails trigger đúng.

## ACCEPTANCE (user-visible)

- Đơn DELIVERED → tạo RMA (chọn items + lý do) → admin duyệt → đánh dấu nhận hàng → refund → tiền về Stripe test wallet; email từng bước trong Mailpit.
- RMA ngoài 7 ngày / sai trạng thái → bị chặn với lý do rõ.
- Đổi địa chỉ giao (tỉnh khác) → phí ship GHN khác flat-fee; đơn có tracking code → my-orders thấy trạng thái vận đơn.
- Mua đơn CONFIRMED → nhận điểm (1%); đơn sau dùng điểm → tổng giảm, ledger trừ đúng; hủy đơn → hoàn điểm.
