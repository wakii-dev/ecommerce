## Spec slice (chỉ phần SF-15 chịu trách nhiệm)

1. **Social login (B3a)** — identity-service: Spring OAuth2 client cho Google + Facebook (env `OAUTH_GOOGLE_CLIENT_ID/SECRET`, `OAUTH_FACEBOOK_*`; không có key → nút login ẩn). Flow: `GET /api/identity/oauth/{provider}` → redirect provider → callback `/api/identity/oauth/{provider}/callback` → find-or-create user (provider_id unique) → JWT như login thường + refresh cookie. Link tài khoản: email trùng user có sẵn → liên kết (không tạo duplicate). UI: nút "Đăng nhập với Google/Facebook" trên login/register pages (mfe-account — edit nhỏ SF-3 đã merge).
2. **2FA TOTP (B3b)** — identity-service: bảng `two_factor` (user_id unique, secret encrypted, enabled, backup_codes hashed). APIs: `POST /api/identity/2fa/setup` (auth) → secret + QR (otpauth URL render client) + 10 backup codes; `POST /api/identity/2fa/enable` (verify mã đầu tiên); `POST /api/identity/2fa/disable` (password + mã); login flow: password đúng + 2FA enabled → trả `{two_factor_required: true}` → `POST /api/identity/2fa/verify` (mã TOTP/backup) → tokens. UI: bật/gắt trong profile (mfe-account edit nhỏ) + trang nhập mã khi login.
3. **Stock alert (B4)** — catalog-service: bảng `stock_alerts` (id, user_email, product_id, variant_id, status ACTIVE/NOTIFIED, created_at). API `POST /api/catalog/products/{slug}/stock-alert` (email + variant, public với email đã xác nhận? MVP: nhận email thuần). Checker scheduler: variant hết hàng có alerts + availability > 0 (gọi inventory) → gửi email restock qua notification (file-slice SF-15 trong notification-service: template + consumer/scheduler) → đánh dấu NOTIFIED. UI: PDP hết hàng → input "Nhắn tôi khi có hàng" (client component — storefront-web edit nhỏ, file-slice).
4. **PWA (B6a)** — storefront-web: `manifest.json` (name, icons — dùng logo direction, theme_color tokens) + service worker cơ bản (precache shell assets, network-first cho API) qua `next-pwa` hoặc手-written SW (agent chọn — ghi rõ); metadata `applicationName` + apple-touch-icon.
5. **Dark mode (B6b)** — ui-kit tokens đã có 2 theme storefront/admin; thêm variant `dark` cho storefront (CSS vars toggle `data-theme="dark"`) + toggle component (header Next + shell, lưu localStorage, respect `prefers-color-scheme` mặc định). áp cho toàn bộ pages + admin (admin dark optional — ưu tiên storefront).
6. **Live chat (B7)** — storefront-web + shell: widget embed script (env `LIVECHAT_LICENSE_ID` — Crisp/Tawk format; không có env → không load). Không tự viết chat engine.
7. **IT tests**: OAuth callback (mock provider WireMock) find-or-create + link email; 2FA enable/login-with/backup-code/disable; stock alert register → restock → email 1 lần; PWA manifest 200 + SW register; dark toggle persist.
